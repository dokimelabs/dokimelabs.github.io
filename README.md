# dokimelabs.github.io

The organization's root site, published from `distribution/dokimelabs.github.io`
of the theia source (one orphan commit per publish — this repository carries no
history of its own). It exists for files that must sit at the root of the
domain:

- `.well-known/microsoft-identity-association.json` — Microsoft's publisher
  verification for the theia installer's sign-in app.

theia itself is installed from https://dokimelabs.github.io/get-theia/.
